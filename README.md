# AI Action Guardrail System with Human-in-the-Loop (HITL)

## Overview

The **AI Action Guardrail System** is a production-ready policy enforcement layer for AI agents. Unlike traditional guardrail systems that validate only prompts and model responses, this system evaluates **AI-generated tool actions before execution**.

Every tool call generated by the AI agent is intercepted by the Action Guardrail Engine and evaluated against configurable policy rules. Based on the policy evaluation, the action is either:

- ✅ Allowed
- ❌ Blocked
- 👤 Paused for Human-in-the-Loop (HITL) approval

This ensures governance occurs at the **moment of execution**, preventing unsafe or unauthorized actions before they are performed.

---

# Problem Statement

Current AI guardrail platforms primarily focus on filtering user prompts and LLM responses. However, once an AI agent decides to execute a tool (such as deleting database records or sending emails), there is often no policy enforcement before execution.

This project addresses that gap by introducing a runtime **Action Guardrail Engine** that evaluates every tool call against declarative policies before allowing execution.

# System Architecture

```text
+------------------------------------------------------+
|                     USER                             |
+------------------------------------------------------+
                      |
                      | Natural Language Prompt
                      v
+------------------------------------------------------+
|              AI AGENT (Google Gemini)                |
+------------------------------------------------------+
                      |
                      | Structured Tool Call
                      v
+------------------------------------------------------+
|            ACTION GUARDRAIL ENGINE                   |
|        (Policy Evaluation Before Execution)          |
+------------------------------------------------------+
                      |
          +-----------+-----------+
          |           |           |
          |           |           |
          v           v           v
      +--------+  +--------+  +------------------+
      | ALLOW  |  | BLOCK  |  | REQUIRE HITL     |
      +--------+  +--------+  +------------------+
          |           |              |
          |           |              |
          v           |              v
+----------------+    |      +-------------------+
| Execute Tool   |    |      | Human Approval    |
+----------------+    |      +-------------------+
          |           |              |
          |           |      Approve / Reject
          |           |              |
          +-----------+--------------+
                      |
                      v
+------------------------------------------------------+
|                 AUDIT DATABASE                       |
| (Logs Prompt, Tool, Decision, Rule & Timestamp)      |
+------------------------------------------------------+
```

**Architecture Description**

Every user request is first processed by the AI Agent (Google Gemini), which converts the natural language prompt into a structured tool action. Before any tool is executed, the Action Guardrail Engine evaluates the request against configurable YAML policy rules. Depending on the policy decision, the action is either allowed, blocked, or paused for Human-in-the-Loop (HITL) approval. Every evaluated action is permanently recorded in the Audit Database for traceability, accountability, and governance.

# Installation

## 1. Clone the Repository

```bash
git clone https://github.com/Susanna-Sherin/ai-action-guardrail-system.git
```

## 2. Navigate to the Project

```bash
cd ai-action-guardrail-system
```

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## 4. Configure Environment Variables

Create a `.env` file and add your Google Gemini API key.

```env
GEMINI_API_KEY=YOUR_API_KEY
```

## 5. Run the Application

```bash
uvicorn backend.main:app --reload
```

## 6. Open in Browser

```
http://localhost:8000
```
